## Bot multi uso (calculo de porcentagem, area, juros composto, velocidade por hora)
Olá! Meu nome é Cássio, e este é meu projeto de conclusão de curso de programação Python, a ideia do meu bot é ser simples, mas eficaz, auxiliando algumas duvidas complexas ou simples, como saber quanto lucrará em um investimento, quanto tempo demorará uma viagem, qual é o desconto dado de um produto para o valor original, entre outros. Apenas de sua simplicidade e pouco, é muito mais util e prático do que se imagina.

O bot é simples, ao iniciar em um servidor, ele dará uma mensagem informando que está ligado e passará o primeiro comando: '-ajuda', com isso, você pode ver todas as possibilidades que o bot pode fazer.

O bot terá mais coisas, como analise de imagens, criar imagens de texto, guarda informções, e muito mais.
